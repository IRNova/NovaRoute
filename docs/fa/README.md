## قرارداد نگارشی این مستندات

هر واژهٔ لاتین، مسیر فایل، نام متغیر و دستور داخل بک‌تیک (`code`) نوشته شده است. دلیلش فنی است: متن فارسی راست‌به‌چپ است و اگر یک عبارت لاتین بدون جداکننده در آن بیاید، ترتیب نمایشش در ترمینال و مرورگر به هم می‌ریزد.

## خلاصهٔ یک‌خطی پروژه

`NovaRoute` یک نقطهٔ پایانی سازگار با `OpenAI` (`/v1`) بالا می‌آورد، درخواست را به یکی از ۳۶۸ ارائه‌دهندهٔ ثبت‌شده می‌فرستد، قالب درخواست و پاسخ را بین `OpenAI`، `Claude`، `Gemini` و بقیه ترجمه می‌کند، و همهٔ اینها را با یک داشبورد وب و یک پایگاه‌دادهٔ `SQLite` تک‌فایلی مدیریت می‌کند.
